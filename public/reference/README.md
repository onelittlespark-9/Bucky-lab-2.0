# Radiography reference diagrams

Bucky Lab includes 38 examination projections, each with a positioning and collimation SVG (76 assets in total). The 72 new diagrams are original simplified teaching schematics. They are not patient photographs, anatomical reconstructions or replicas of Clark's Positioning in Radiography.

These diagrams represent approximate limb and trunk orientation, receptor field and centring. Their anatomy is stylised and not to scale. Exact patient positioning, especially in trauma, requires assessment using current departmental guidance and supervised instruction. Do not mistake the vector images for clinically validated replicas.

Diagram names are `<projection-id>-position.svg` and `<projection-id>-collimation.svg`. The positioning library maps directly from the IDs in the X-ray examination list, and automated browser checks load every asset on desktop and mobile.

References consulted for terminology:
- https://radiopaedia.org/articles/pelvis-ap-view-1
- https://radiopaedia.org/articles/knee-lateral-view
- https://radiopaedia.org/articles/hand-pa-view-2
- https://radiopaedia.org/articles/wrist-lateral-view-2
- https://radiopaedia.org/articles/forearm-series

The pre-existing elbow SVGs remain unchanged. No third-party textbook artwork is embedded in the new SVGs.
